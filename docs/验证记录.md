## 来源和改动范围

来自文档数据库开发分支的工作区最新源码，包含未归档的当前用户文字提示。未复制旧 Git 历史。文档库事务服务、数据库适配、正式 UID 授权、业务接口、恢复和导出实现保留；MySQL 历史实现及其测试保留，不误称其为当前云端后端。

展示适配仅包括：重写文档；虚构测试账号标识；152条虚构数据补充示例小组；默认入口启动本地模拟；强制前端使用示例名单；云连接明确开关、代理限制回环地址；隔离测试端口；截图测试和截图。旧哈希兼容测试改为显式构造旧格式名单，以继续验证没有小组字段时的兼容性。未更改发号、纠正、UUID、事务和 Excel 业务算法。

## 安全核查

对准备公开的源码、配置、文档及生成的前端/后端产物进行扫描，并与本地两份真实名单共300条记录的姓名、企业、小组值及最新5个实际 UID 对照；检查本地凭据值、密码/密钥特征、生产资源标识和手机号特征。核查结果未发现匹配。原始对照资料及逐值扫描内容没有复制到展示目录。

未复制真实 JSON/Excel、账号配置、环境文件、云快照、实际请求记录、回退备份、日志、原静态构建或互联网快捷方式。展示账号名称为虚构测试标识，服务端白名单模板为空。展示目录未配置 GitHub 远端；只有一份独立本地历史，不含原仓库提交作者和历史文件。

三张截图实际查看，均为“示例学员/虚构企业/示例学习组”，包含明确模拟标识；没有真实名单或账号。仅 `docs/images/*.png` 是截图忽略规则例外。所有运行数据、下载 Excel、测试报告、构建及缓存排除。

扫描不能数学证明所有敏感信息绝不存在；本轮未发现阻止公开的内容。发布前仍应审阅最终提交树及截图，本次没有创建或发布 GitHub 仓库。原系统源码工作区、真实数据和线上资源均未更改。
